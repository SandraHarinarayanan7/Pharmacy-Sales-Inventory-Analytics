# Pharmacy Sales & Inventory Analytics – Power BI

## Project Overview

This project focuses on analyzing pharmacy sales and inventory data using Power BI. The dashboard provides an interactive view of sales performance, medicine demand, revenue, pricing, discounts, transactions, and sales channel distribution.

The project involved data cleaning, data transformation, column creation, and exploratory analysis before developing the final Power BI dashboard. The analysis converts raw pharmacy transaction data into meaningful visual insights that can support better understanding of sales performance, product demand, and inventory-related trends.

## Objectives

- Analyze overall pharmacy sales and revenue performance
  
- Identify medicine categories with higher demand
  
- Compare revenue across different cities
  
- Analyze revenue distribution across sales channels
  
- Examine monthly revenue trends
  
- Compare revenue performance across pharmacy types
  
- Understand pricing and discount patterns
  
- Provide an interactive dashboard for exploring key business metrics

## Data Preparation

The dataset was cleaned and prepared before being used for analysis. The data preparation process included reviewing the dataset, handling data inconsistencies, formatting fields appropriately, and creating additional columns required for analysis and visualization.

These prepared fields were then used to build meaningful measures, KPIs, and visualizations in Power BI.

## Dashboard Highlights

The dashboard provides insights into:

- Total Revenue
  
- Total Units Sold
  
- Average Unit Price
  
- Average Discount
  
- Total Transactions
  
- Revenue by City
  
- Medicine Demand by Category
  
- Revenue Distribution by Sales Channel
  
- Revenue by Pharmacy Type
  
- Monthly Revenue Trends
  
- Revenue by Medicine Category

## Tools & Technologies

## Key Insights

The dashboard helps identify variations in revenue and medicine demand across cities and medicine categories. It also highlights differences in sales performance across pharmacy types and sales channels, while providing an overview of monthly revenue trends and key transaction metrics.

## Conclusion

This project demonstrates the use of data cleaning, transformation, analysis, and visualization techniques to convert pharmacy transaction data into an interactive Power BI dashboard. The dashboard presents key sales and inventory-related metrics through clear KPIs and visualizations, making it easier to identify trends, compare performance, and derive meaningful business insights.
